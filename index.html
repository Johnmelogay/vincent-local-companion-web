Connection & API

Install Vincent on iPhone
In Safari, tap Share → Add to Home Screen → Add. Keep “Open as Web App” enabled if offered. Vincent opens as its own app with the portrait icon. The app shell opens offline; replies still require your Mac to be awake and connected.

The model runs on your Mac. It must be awake and connected to the internet. Anyone with this link can use the isolated public interface.

POST /v1/chat/completions with a JSON messages array. GET /v1/models lists the model. WebSocket /ws provides chat and voice events.

To share your full personal history with this browser, open “My personal website” from the desktop app's Preferences. Keep that private connection link to yourself.

Unpaired visitors cannot access the owner's private conversations, memory, files or terminal. Requests and uploads pass through the HTTPS tunnel to the Mac. Text extraction supports text PDFs and DOCX; scanned documents and images are not supported.
